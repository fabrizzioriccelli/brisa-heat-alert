# Identidade visual do Brisa

| Uso | Cor | Hex |
|---|---|---|
| Fundo escuro (vídeo, capa) | Noite | `#0F1B2D` |
| Fundo claro | Areia | `#FFF8F0` |
| Texto principal | Grafite | `#1D2433` |
| Destaque frio (a "brisa") | Água | `#3BB3C3` |
| Gradiente de calor (logo) | Vinho → Vermelho → Âmbar | `#7A1F3D` → `#D63E2F` → `#F5A623` |
| Faixas de risco | Normal · Cautela · Cautela extrema · Perigo · Perigo extremo | `#2E9E6B` · `#E8C547` · `#F08A24` · `#D63E2F` · `#7A1F3D` |

**Tipografia:** Avenir Next (títulos e interface), Charter/Georgia (texto longo do relatório) e Menlo (código).
**Marca:** três linhas de vento sobre o gradiente de calor ([`brisa-mark.svg`](brisa-mark.svg), [`brisa-logo.svg`](brisa-logo.svg)). O vento (a brisa) alivia o calor.
